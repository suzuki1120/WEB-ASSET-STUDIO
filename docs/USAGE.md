# Web Asset Studio 利用マニュアル

Web Asset Studio は、計算ツール4種と、画像・動画の変換ツールをまとめたブラウザ上のツールです。ファイルの処理はすべて手元のブラウザ内で行い、サーバーへは送信しません。起動方法は [README.md](../README.md) を参照してください。

## 1. 画面構成

画面は次の3つの領域に分かれます（幅 1280px 以上の場合）。

| 領域 | 位置 | 内容 |
| --- | --- | --- |
| サイドバー | 左 | ツールの一覧、テーマ切替ボタン、ブラウザ機能の確認結果 |
| 作業エリア | 中央 | 入力欄やファイルの一覧、結果、操作バー |
| 設定パネル | 右 | 変換ツールの設定。計算ツールでは表示されません |

### サイドバー

「計算」に4つ、「変換」に2つのツールが並びます。クリックすると、右側の作業エリアが切り替わります。URL の末尾も切り替わります（`#/percent`、`#/vw`、`#/ratio`、`#/clamp`、`#/images`、`#/video`）。よく使うツールは、そのURLをブックマークしておくと便利です。

サイドバーの最下部には、ブラウザ機能の確認結果が出ます（画面幅 1280px 以上で表示）。

| 表示 | 意味 |
| --- | --- |
| `WebCodecs ✓` | 動画を高速に変換できます |
| `WebCodecs 未対応` | 動画の変換は、再生しながら録画する方式になります |
| `AVIF ✓` / `AVIF –` | AVIF の書き出しに必要な機能が使えるか（`–` は使えません） |

### 画面幅による表示の違い

| 画面幅 | 表示 |
| --- | --- |
| 1280px 以上 | 3列（サイドバー、作業エリア、設定パネル） |
| 900px から 1279px | サイドバーがアイコンだけの細い列になります |
| 600px から 899px | サイドバーが上部の横並びナビになります。設定パネルは「設定」ボタンで開閉します |
| 600px 未満 | 1列表示になり、操作バー（変換開始・保存など）が画面下に固定されます |

「設定」ボタンの開閉状態は記憶されます。

### テーマの切り替え

サイドバー下部の「テーマ」ボタン（太陽または月のアイコン）で、ライトとダークを切り替えます。初回は OS の設定に従います。切り替えた後は、選んだテーマを記憶します。

### キーボードショートカット

Mac は Cmd、Windows は Ctrl を使います。

| 操作 | 動作 |
| --- | --- |
| Cmd/Ctrl + 1 から 6 | サイドバーの上から順にツールを切り替えます（1: px → %、2: px → vw、3: アスペクト比、4: Fluid clamp()、5: 画像変換、6: 動画変換） |
| Cmd/Ctrl + Enter | 画像変換・動画変換の画面で、選択中のファイルの変換を開始します |
| Cmd/Ctrl + V | 画像変換の画面で、クリップボードの画像を追加します |

## 2. 計算ツール

入力した値は自動で計算され、結果が即座に表示されます。結果の表示部分をクリックすると、値がクリップボードにコピーされます。入力値は次回も記憶されます。

### px → %

親要素のサイズに対して、対象のサイズが何 % にあたるかを求めます。

| 入力 | 内容 |
| --- | --- |
| 親要素のサイズ | 割合の基準になる値（px）。0 より大きい値 |
| 対象のサイズ | 割合を知りたい値（px） |

- 結果：割合（小数第3位まで）。例：親要素 1000、対象 500 → `50%`
- コピーされる形式：数値と単位（`50%`）

### px → vw

画面幅に対して、対象のサイズが何 vw にあたるかを求めます。1vw は画面幅の1%です。デザインカンプの寸法を、画面幅に比例する値へ置き換えるときに使います。

| 入力 | 内容 |
| --- | --- |
| 画面幅 | デザインカンプの幅（px） |
| 対象のサイズ | 変換したい値（px） |

- 結果：vw の値（小数第3位まで）。例：画面幅 1440、対象 720 → `50vw`
- コピーされる形式：数値と単位（`50vw`）

### アスペクト比

幅と高さを最大公約数で約分し、CSS に書ける比率を求めます。小数を入力した場合は、整数に丸めてから約分します。

| 入力 | 内容 |
| --- | --- |
| 幅 | px |
| 高さ | px |

- 結果：例：1920 × 1080 → `16 / 9`
- 結果をクリックすると `16 / 9` をコピーします。
- 「aspect-ratio をコピー」ボタンを押すと、`aspect-ratio: 16 / 9;` の形でコピーします。

### Fluid clamp()

画面幅が最小値から最大値へ広がる間に、サイズが滑らかに変わる `clamp()` を生成します。見出しの文字サイズなどを、画面幅に合わせて自然に変えたいときに使います。

| 入力 | 内容 | 初期値 |
| --- | --- | --- |
| 最小サイズ | 画面が最小幅のときのサイズ（px） | 空欄 |
| 最大サイズ | 画面が最大幅のときのサイズ（px） | 空欄 |
| 最小画面幅 | サイズの変化を始める画面幅（px） | 320 |
| 最大画面幅 | サイズの変化を終える画面幅（px） | 1280 |
| ルートのフォントサイズ | rem に換算するときの基準（px）。通常は 16 | 16 |
| 出力単位 | `rem` または `px` | rem |

- 結果の例（最小 16px、最大 24px、画面幅 320 から 1280、rem）：`clamp(1.000rem, 0.833rem + 0.833vw, 1.500rem)`
- コピーされる形式：`clamp(...)` の文字列全体
- 次の場合は、結果欄にメッセージが出ます。
  - 項目が空欄：「すべての項目を入力してください」
  - 最小画面幅と最大画面幅が同じ値：同じ値は指定できない旨
  - ルートのフォントサイズが 0 以下：0 より大きい値にする旨

## 3. 画像変換

JPEG、PNG、WebP、AVIF、GIF の画像を、WebP、AVIF、JPEG、PNG に一括で変換します。複数の形式と複数のサイズを同時に書き出せます。GIF は静止画として扱われ、アニメーションは保持されません。

### 基本の流れ

1. 画像を追加します。
2. 右の設定パネルで、出力形式やサイズを決めます。
3. 画面下の「変換を開始」を押します。
4. 結果を確認し、保存します。

### 画像を追加する

次のどれでも追加できます。複数枚をまとめて追加できます。

| 方法 | 操作 |
| --- | --- |
| ドロップ | 点線の枠に画像ファイルをドラッグして離します |
| クリック | 枠をクリックしてファイル選択ダイアログを開きます（キーボードでは Enter か Space） |
| ペースト | Cmd/Ctrl + V で、クリップボードの画像を追加します |

- 画像でないファイルをドロップすると、「対応していない形式の N 件を無視しました」と表示され、画像だけが追加されます。
- 名前、サイズ、更新日時がすべて同じファイルは、重複として追加されません（「すでに追加済みの画像です」と表示されます）。
- 追加した画像はカードで一覧表示されます。カードのチェックボックスで、変換する画像を選べます。画面下の「全選択」でまとめて切り替えられます。
- 読み込めない画像は、追加した時点でカードに「エラー」と「画像を読み込めませんでした」が表示されます。

### 設定パネルの項目

「出力形式」と「リサイズ」は初めから開いています。「srcset」「ファイル名」「コード出力」「プリセット」は、見出しをクリックして開きます。設定を変えると自動で保存されます。

#### 出力形式

使う形式にチェックを入れます。初期状態では WebP だけが有効です。1つ以上の形式を選ばないと変換できません。

| 形式 | 項目 | 初期値 | 意味と推奨値 |
| --- | --- | --- | --- |
| WebP | 品質 | 80 | 1 から 100。大きいほど高画質でファイルも大きくなります。75 から 85 が目安です |
| WebP | 可逆圧縮 | オフ | オンにすると画質が劣化しませんが、ファイルは大きくなります。オンの間、品質は使われません |
| WebP | 圧縮の手間 | 4 | 0 から 6。大きいほど時間がかかり、ファイルは小さくなります。通常は初期値で十分です |
| AVIF | 品質 | 60 | 1 から 100。50 から 65 が目安です。WebP より低い数値でも同程度の見た目になります |
| AVIF | 可逆圧縮 | オフ | WebP と同じ考え方です |
| AVIF | 圧縮の手間 | 6 | 0 から 9。大きいほど遅く、小さくなります。枚数が多いときは 4 から 6 に抑えてください |
| JPEG | 品質 | 82 | 1 から 100。75 から 85 が目安です |
| JPEG | 背景色 | 白 | JPEG は透明を扱えないため、透明な部分をこの色で塗りつぶします |
| PNG | なし | なし | 常に可逆圧縮です。設定項目はありません |

AVIF を選ぶと「AVIFはエンコードに時間がかかります」という注意が出ます。

形式の使い分けの目安は次のとおりです。

- 写真：AVIF と WebP を併用し、古いブラウザ向けに JPEG を添えます。
- ロゴやアイコンなど、透明が必要な画像：WebP（または PNG）を使います。
- 画質を落としたくない素材：可逆圧縮の WebP か PNG を使います。

#### リサイズ

「指定方法」で、サイズの決め方を選びます。初期値は「なし」（元のサイズのまま）です。

| 指定方法 | 入力 | 動作 |
| --- | --- | --- |
| なし | なし | 元のサイズで書き出します |
| 幅 | 幅（px） | 幅を指定し、高さは縦横比を保って決まります |
| 高さ | 高さ（px） | 高さを指定し、幅は縦横比を保って決まります |
| 倍率 | 倍率（%） | 元のサイズに対する割合で縮小します。50 なら半分です |
| 枠 | 幅と高さ（px） | 指定した枠に合わせます。合わせ方は下表のとおりです。幅か高さのどちらか1つだけでも指定できます（その場合は幅指定、高さ指定と同じ動作です） |

「枠」を選んだときの「枠への合わせ方」は次の3つです。

| 合わせ方 | 動作 |
| --- | --- |
| 枠内に収める（余白なし） | 縦横比を保ったまま、枠に収まる最大のサイズにします。枠より小さくなることがあります |
| 枠を埋めて中央で切り抜く | 枠いっぱいに拡大または縮小し、はみ出した部分を中央基準で切り落とします。サムネイル向きです |
| 縦横比を無視して引き伸ばす | 枠のサイズにそのまま合わせます。画像が歪むことがあります |

「拡大を許可」がオフの間は、元の画像より大きいサイズを指定しても拡大しません（元のサイズが上限になります）。拡大して書き出したい場合だけオンにしてください。

#### srcset

srcset は、画面幅に応じてブラウザが読み込む画像を選べるように、同じ画像を複数の幅で用意する HTML の仕組みです。スマートフォンには小さい画像、大きな画面には大きい画像が配信されます。

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| 複数サイズを書き出す（srcset） | オフ | オンにすると、下の2項目が表示されます |
| 書き出す幅 | 480, 768, 1024, 1440, 1920 | px をカンマか空白で区切って入力します。元の画像（またはリサイズ後）の幅より小さいものだけが書き出されます |
| 元のサイズも含める | オン | リサイズ後のサイズ（リサイズなしなら元のサイズ）を、最大の幅として追加します |

例：元の幅が 1600px、初期の幅の指定で「元のサイズも含める」がオンの場合は、480、768、1024、1440、1600 の 5 サイズが書き出されます。

注意：出力数は「形式の数 × サイズの数」になります。3形式と5サイズなら、1枚の画像から 15 ファイルが作られます。

#### ファイル名

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| ファイル名パターン | `{name}{suffix}.{ext}` | 使えるのは `{name}`（元のファイル名）、`{w}`（幅）、`{h}`（高さ）、`{ext}`（拡張子）、`{suffix}`（サイズ違いの接尾辞）です。`{ext}` は必須です |
| サイズ違いの接尾辞 | `-{w}w` | `{w}` は幅、`{h}` は高さに置き換わります |
| 小文字にそろえる | オフ | ファイル名全体を小文字にします |
| 元の名前を URL 向けに整える | オフ | 元の名前の空白を `-` にし、記号を取り除きます（日本語の文字は残ります） |

パネルに「例: …」としてファイル名の見本が出るので、確認しながら調整してください。

- 接尾辞は、srcset がオンのとき、またはリサイズで元と違うサイズになるときに付きます。元のサイズのまま1サイズだけ書き出す場合は付きません（`photo.webp`）。
- 同じ名前のファイルができた場合は、拡張子の前に `-2`、`-3` が自動で付きます（大文字小文字は区別しません）。

#### コード出力

「コードをコピー」で作られる HTML の設定です。

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| パスの接頭辞 | `/assets/img/` | `src` と `srcset` の先頭に付けるパスです。実際の配置場所に合わせて変更してください |
| sizes 属性 | `(max-width: 768px) 100vw, 768px` | 画像が画面でどれだけの幅を占めるかをブラウザに伝える値です。サイズ違いが2つ以上あるときだけ出力されます |
| 遅延読み込み（lazy） | オン | `loading="lazy"`（画面に近づいてから読み込む）と `decoding="async"` を付けます |

#### プリセット

よく使う設定の組み合わせを、ボタン1つで適用します。

| ボタン | 内容 |
| --- | --- |
| Web標準 | WebP（品質 80）と JPEG（品質 82）。srcset をオン（元のサイズも含める） |
| 高品質 | AVIF（品質 65、手間 6）、WebP（品質 90、手間 5）、JPEG（品質 92） |
| サムネイル | WebP（品質 70）。リサイズは枠 320 × 320 px、切り抜き |
| 既定に戻す | すべての設定を初期値に戻します |

プリセットを適用すると、そこに含まれない項目（ファイル名、コード出力など）も初期値に戻ります。適用前に、必要な設定をメモしておいてください。

### 変換を実行する

- 画面下の「変換を開始」（または Cmd/Ctrl + Enter）で、チェックが入っている画像を変換します。
- すでに変換済みの画像にチェックが入っていれば、その画像も変換し直します。
- 変換中、ボタンは「キャンセル」に変わります。押すと、処理待ちの画像は「中止」になります。
- 複数枚は並行して処理されます（お使いのブラウザが対応している場合）。
- 各カードには、状態（待機中、変換中、完了、エラー、中止）と進捗が表示されます。
- 設定が不足している場合は、変換の前に理由が表示されます（例：「出力形式を1つ以上選んでください」「リサイズの幅を入力してください」）。

### 結果の見方

完了したカードには、出力ファイルごとに1行が表示されます。

| 表示 | 内容 |
| --- | --- |
| ラベル | 形式とサイズ（例：`WEBP 1600×900`） |
| ファイルサイズ | 出力ファイルの大きさ |
| 削減率 | 元のファイルに対する増減。`-81%` なら 81% 小さくなったことを示します（緑）。`+20%` のように増えた場合は赤で表示されます |
| 保存アイコン | その1ファイルだけを保存します |

画面下の操作バーには、全体の集計が出ます（例：`3ファイル → 9出力 · 4.20 MB → 1.10 MB (-74%)`）。この削減率は、すべての出力の合計と元ファイルの合計を比べた値です。形式やサイズを増やすと出力の合計が増えるため、プラスの値になることもあります。この場合でも、個々の出力の削減率は別に確認できます。

### 設定を変えたとき（再変換）

変換後に設定を変えると、完了済みのカードに「設定が変更されました」と表示されます。結果は自動では更新されません。更新するには、次のどちらかを行います。

- カードの更新アイコン（再変換）を押す。その1枚だけを変換し直します。
- 画面下の「変換を開始」を押す。チェックが入っているすべての画像を変換し直します。

### 保存する

| 方法 | 操作 | 内容 |
| --- | --- | --- |
| 個別 | 出力行の保存アイコン | その1ファイルを保存します |
| ZIP | 「ZIPでダウンロード」 | チェックが入っている画像の出力すべてを、`images.zip` にまとめます |
| フォルダ | 「フォルダに保存」 | 選んだフォルダにファイルを直接書き込みます。Chrome と Edge でのみ表示されます。同名のファイルがフォルダにある場合は上書きされます |

ZIP は圧縮せずにまとめます。画像はすでに圧縮されているためです。

### HTML のコードをコピーする

完了したカードの「コードをコピー」を押すと、書き出した画像を使う HTML がコピーされます。

- 複数の形式がある場合は `<picture>` タグになります。AVIF、WebP の順に `<source>` が並び、JPEG（なければ PNG、WebP、AVIF の順）が `<img>` の代わりの画像になります。
- 1形式だけの場合は `<img>` タグになります。
- `alt` は空で出力されます。画像の内容に合わせて、貼り付け後に書き換えてください。
- `width` と `height` には最大サイズの値が入ります（レイアウトのずれを防ぐためです）。

出力例（AVIF、WebP、JPEG に 480px と 1600px がある場合。長い属性は省略しています）：

```html
<picture>
  <source type="image/avif" srcset="/assets/img/photo-480w.avif 480w, /assets/img/photo-1600w.avif 1600w" sizes="(max-width: 768px) 100vw, 768px">
  <source type="image/webp" srcset="/assets/img/photo-480w.webp 480w, /assets/img/photo-1600w.webp 1600w" sizes="(max-width: 768px) 100vw, 768px">
  <img src="/assets/img/photo-1600w.jpg" srcset="..." sizes="..." width="1600" height="900" alt="" loading="lazy" decoding="async">
</picture>
```

### エラーが起きたとき

- 失敗した画像のカードには「エラー」の表示と理由が出ます。ほかの画像の変換は止まらず、続けて処理されます。
- 変換の終了時に、「3件が完了、1件でエラーが発生しました」のように件数が表示されます。
- 主な理由は次のとおりです。

| 表示 | 原因と対処 |
| --- | --- |
| 画像を読み込めませんでした | ファイルが壊れているか、ブラウザが対応していない形式です。別の画像で試してください |
| AVIFエンコーダを読み込めませんでした | ライブラリの読み込みに失敗しています。ネット接続を確認してください |
| WebPエンコーダを読み込めませんでした | ライブラリを読み込めず、ブラウザの機能でも WebP を書き出せない状態です。ネット接続を確認するか、Chrome か Edge を使ってください |
| このブラウザは（形式名）の書き出しに対応していません | ブラウザが指定の形式で書き出せません。Chrome か Edge を使ってください |

- エラーになったカードの更新アイコンで、その1枚だけ再実行できます。
- カードのごみ箱アイコンで1枚を削除します。画面下の「クリア」は、確認のうえ、すべての画像と結果を削除します。

## 4. 動画変換

MP4、MOV、WebM、M4V の動画を、WebM または MP4 に変換します。トリム（開始位置と終了位置を切り出すこと）や画面サイズの変更もできます。

### 動画を追加する

画像と同じく、ドロップまたはクリックで追加します（複数可）。追加すると、動画の長さ、画面サイズ、FPS（1秒あたりのコマ数）、コーデック（映像の圧縮方式）を自動で調べ、カードに表示します。

動画を追加すると、作業エリアにプレビューが出ます。動画が2本以上あるときは、「プレビュー対象」で表示する動画を切り替えられます。

### 対応状況の表示の読み方

お使いのブラウザで何ができるかは、次の場所に表示されます。

| 場所 | 表示 | 意味 |
| --- | --- | --- |
| 作業エリア上部（青） | 「WebCodecsで高速変換」 | WebCodecs（ブラウザ内蔵の動画エンコード機能）が使えます。再生時間より短い時間で変換できる場合が多い方式です |
| 作業エリア上部（黄） | 「この環境では WebCodecs を使えないため、リアルタイム変換（MediaRecorder）で処理します。再生時間と同じ時間がかかります」 | 再生しながら録画する方式で変換します |
| 設定パネルの下部（黄） | 「このブラウザでエンコードできないコーデック（…）」 | 一覧のコーデックは使えません。選択肢が無効（「未対応」の表示）になっています。使えないものがない場合は表示されません |
| サイドバー下部 | `WebCodecs ✓` など | 前述のとおりです（画面幅 1280px 以上） |

### 設定パネルの項目

設定は、一覧にあるすべての動画に共通して適用されます。

#### 出力

| 項目 | 選択肢 | 内容 |
| --- | --- | --- |
| コンテナ | WebM / MP4 | 出力するファイル形式です |
| 映像コーデック | WebM：VP9、VP8、AV1 / MP4：H.264、H.265、AV1 | コンテナを切り替えると、使えるものだけが並びます。ブラウザが対応していないものは選べません。初期値は WebM と VP9 です |
| 変換方法 | 再エンコード / コピー（高速） | 下の説明を参照してください |

変換方法の違いは次のとおりです。

- 再エンコード：映像を圧縮し直します。解像度、FPS、ビットレートの設定が反映されます。
- コピー（高速）：元の映像をそのまま取り込みます。出力形式で使えないコーデックのときだけ変換します。解像度、FPS、ビットレートの設定は無視されます（設定欄は薄く表示されます）。再生しながら録画する方式（MediaRecorder）では、コピーを選んでも録画し直す点に注意してください。

#### 解像度

「元のまま」「幅」「高さ」「倍率」「枠」から選びます。考え方は画像のリサイズと同じです。動画では、コーデックの都合で、幅と高さは偶数にするのが安全です（入力欄は 2 刻みです）。

「枠」の「枠へのはめ方」は、「収める（余白あり）」「埋める（はみ出しを切り取り）」「引き伸ばす」から選びます。

#### フレームレート

「元のまま」「24 fps」「30 fps」「60 fps」から選びます。fps は1秒あたりのコマ数です。数値を下げるとファイルは小さくなりますが、動きは粗くなります。

#### ビットレート

ビットレートは、1秒あたりの映像データ量です。大きいほど高画質でファイルも大きくなります。

| 指定方法 | 内容 |
| --- | --- |
| プリセット | 「低（小さいファイル）」「中」「高」「最高」から選びます。初期値は「高」です。実際の値は、画面サイズやコーデックに応じて自動で決まります |
| 指定 | kbps（1秒あたりのキロビット数）で直接入力します。100 から 100000、初期値は 4000（4 Mbps）です |

目安として、Web サイトの背景動画などでは、まず「中」か「高」を試し、ファイルサイズと見た目を確認するとよいでしょう。

#### 音声

| 項目 | 内容 |
| --- | --- |
| 音声を残す / 音声なし | 「音声なし」にすると音声トラックを取り除きます。背景動画のように音が不要な場合は、ファイルが小さくなります |
| 音声コーデック | 「自動」（WebM は Opus、MP4 は AAC。AAC が使えなければ Opus）、または選択肢から指定します |
| 音声ビットレート | 96、128、192、256 kbps から選びます。初期値は 128 kbps です |

再生しながら録画する方式（MediaRecorder）では、音声コーデックと音声ビットレートの指定は反映されません。

#### トリム（切り出し）

プレビューの下にある入力欄で、変換する範囲を秒で指定します。

| 項目 | 内容 |
| --- | --- |
| 開始位置 | 切り出しを始める位置（秒）。初期値は 0 |
| 終了位置 | 切り出しを終える位置（秒）。空欄なら末尾まで |
| 現在位置をセット | プレビューを再生・停止した位置を、そのまま開始位置または終了位置に入れます |

帯のバーと文章で、選んだ範囲と全体の長さが確認できます。トリムの設定は、一覧にあるすべての動画に適用されます。終了位置が開始位置以前の場合は、変換前に注意が表示されます。

#### ポスター画像

ポスターは、動画の再生前に表示する静止画です。「ポスター画像を書き出す」をオンにすると設定欄が表示されます。

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| 時刻 | 0 秒 | 静止画にするフレームの位置（元の動画の先頭からの秒数。トリムの設定とは関係しません） |
| 形式 | JPEG | JPEG、WebP、AVIF から選びます |
| 品質 | 85 | 1 から 100 |
| 幅 | 空欄 | 空欄なら元のサイズです |

ファイル名は `<元の名前>-poster.jpg` のようになります。

### 変換を実行する

- 「変換を開始」（または Cmd/Ctrl + Enter）で、チェックが入っている動画を1本ずつ順番に変換します。
- 変換中は進捗が表示されます。「キャンセル」で中止できます。
- 再生しながら録画する方式のときは、変換中にタブを前面に出したままにしてください。背面に回すと、録画データが空になることがあります。
- 設定の一部がお使いの環境で使えない場合、自動で別のコーデックに切り替わり、その旨が通知されます。
- WebCodecs での変換が、コーデックの未対応などを理由に失敗したときは、再生しながら録画する方式に自動で切り替わります（その旨が通知されます）。

### 変換時間の目安

| 方式 | 時間 |
| --- | --- |
| WebCodecs（高速） | 動画の長さ、画面サイズ、コーデック、パソコンの性能で大きく変わります。同じ動画を短い範囲で試すと、全体の時間を見積もれます |
| MediaRecorder（リアルタイム） | 変換する範囲の再生時間と同じ時間がかかります。1分の動画なら約1分です |

### 結果の保存

完了したカードに、出力ファイルごとの行が表示されます。

| 表示 | 内容 |
| --- | --- |
| ラベル | 例：`WEBM vp9`、`MP4 avc`、`MP4 元コーデック`（コピーのとき） |
| 画面サイズ、ファイルサイズ | 出力ファイルの値 |
| 削減率 | 元のファイルに対する増減（動画のみ。画像と同じ見方です） |
| ダウンロード | その1ファイルを保存します |

- 動画のファイル名は `<元の名前>.webm` または `<元の名前>.mp4` です。元のファイルと同じ拡張子で変換した場合は、同じ名前になるため、保存先で上書きしないよう注意してください。
- 「ZIPでダウンロード」は `videos.zip` に、チェックが入っている動画の出力すべてをまとめます。同名のファイルには `-2` などが付きます。
- 「フォルダに保存」は Chrome と Edge でのみ表示されます。

### `<video>` タグをコピーする

完了したカードの「`<video>` タグをコピー」を押すと、次の形式の HTML がコピーされます。

```html
<video src="/assets/video/sample.webm" poster="/assets/video/sample-poster.jpg" autoplay muted loop playsinline></video>
```

- `poster` は、ポスター画像を書き出した場合だけ付きます。
- パスの先頭は `/assets/video/` で固定です。配置場所が違う場合は、貼り付け後に書き換えてください。
- `autoplay muted loop playsinline` は、背景動画として使う想定の属性です。用途に合わせて調整してください。

## 5. 設定の保存について

各ツールの設定と入力値、テーマ、設定パネルの開閉状態は、ブラウザの localStorage（そのブラウザ内に保存される小さな記録領域）に保存されます。

- 次回開いたときに、前回の設定が再現されます。
- 保存先はブラウザごと、かつ URL（ポート番号を含む）ごとです。別のブラウザや別のポートで開くと、設定は引き継がれません。
- ブラウザのサイトデータを削除すると、設定は初期値に戻ります。
- 追加したファイルと変換結果は保存されません。ページを再読み込みすると消えます。

## 6. よくある質問とトラブル対応

### 画面が古いまま、または修正が反映されない

ブラウザが古いファイルをキャッシュ（一時保存）しています。本ツールは多数のファイルで構成されており、一部だけが古いと動作がおかしくなることがあります。

1. スーパーリロード（Cmd/Ctrl + Shift + R）を行います。
2. 直らない場合は、開発者ツールの「Network」タブで「Disable cache」にチェックを入れ、開いたまま再読み込みします。

### ライブラリを読み込めない

次のような症状が出た場合は、CDN への接続に失敗している可能性があります。

- 「AVIFエンコーダを読み込めませんでした」などのエラーが出る
- ZIP が作れない
- 動画ツールが、WebCodecs が使える環境でも「リアルタイム変換」の表示になる

対処は次のとおりです。

1. ネット接続を確認します。
2. 社内ネットワークや拡張機能が `esm.sh` と `cdn.jsdelivr.net` へのアクセスを遮断していないか確認します。
3. ページを再読み込みして、もう一度試します。

### コーデックを選べない（「未対応」と表示される）

使えるコーデックは、ブラウザ、OS、パソコンの性能によって異なります。たとえば H.265（HEVC）や AV1 は、使えない環境があります。使えるコーデック（WebM なら VP9、MP4 なら H.264 など）を選んでください。

### 動画の変換が進まない、または出力が空になる

再生しながら録画する方式では、タブが背面にあると録画が止まることがあります。変換が終わるまで、このタブを前面に出したままにしてください。

### Safari で使うとき

Safari は動作確認をしていません。次の点に注意してください。

- 画像：WebP のライブラリを読み込めず、ブラウザの機能でも WebP を書き出せない場合は、エラーになります。
- 動画：WebCodecs の対応状況はバージョンで異なります。非対応の場合は、リアルタイム変換になります。
- 「フォルダに保存」は使えません。ZIP か個別保存を使ってください。

うまく動かない場合は、Chrome か Edge をお使いください。

### 追加したのに「すでに追加済み」と表示される

名前、サイズ、更新日時が同じファイルは、重複として追加されません。別の画像として扱いたい場合は、ファイル名を変えてください。

### 変換後のファイルが元より大きい

次を試してください。

- 品質の数値を下げる。
- AVIF や WebP など、圧縮率の高い形式を使う。
- すでに十分に圧縮された画像は、変換しても小さくならないことがあります。

### 設定を初期状態に戻したい

画像変換は、設定パネルの「プリセット」にある「既定に戻す」を使います。すべてのツールの設定を戻す場合は、ブラウザのサイトデータ（localStorage）を削除してください。
